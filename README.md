# IRP LMS — HTML & CSS Assignment

A responsive, three-page recreation of the IRP LMS reference website using HTML5 and CSS3.

## Files
- `index.html` — Home page and five-step learning journey
- `courses.html` — Nine responsive YouTube course embeds
- `contact.html` — Contact information and message form
- `style.css` — Shared responsive design and styling

## Run locally
1. Download and extract the project ZIP.
2. Open the `IRP-LMS` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Use the navigation to check all three pages.

The site uses the supplied Cloudinary image assets and the YouTube embed URLs from the assignment brief. An internet connection is needed to load these remote assets and videos.

## GitHub submission
1. Create a **public** repository on GitHub.
2. Upload all four files (or push the project folder with Git).
3. Open the repository URL in a private/incognito browser window to verify public access.
4. Submit the public repository URL through the assignment submission channel.

## Notes
- Built with HTML and CSS only; no JavaScript or backend is required.
- The Sign In link is a visual placeholder.
- The contact form is a front-end demo and does not send messages to a server.
